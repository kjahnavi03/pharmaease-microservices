🎤 30-SECOND PROJECT PITCH (MEMORIZE THIS!):

"PharmaEase is a microservices-based online pharmacy platform built with 
Spring Boot, Spring Cloud, and Angular. It consists of 9 independent services 
including authentication, catalog management, order processing, and payment 
handling. Services communicate via REST APIs and RabbitMQ for asynchronous 
messaging. I implemented JWT authentication, used Eureka for service discovery, 
and deployed everything using Docker. The system handles the complete e-commerce 
flow from browsing medicines to order delivery, with features like prescription 
approval and email notifications."
