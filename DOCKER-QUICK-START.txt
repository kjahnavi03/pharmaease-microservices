🔧 TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Services not starting
Solution: Wait 3-4 minutes, check logs

Problem: Port already in use
Solution: Stop other services using that port
          Or change port in docker-compose.yml

Problem: Out of memory
Solution: Increase Docker memory in Docker Desktop settings
          Settings → Resources → Memory → 8GB

Problem: Frontend shows 404
Solution: docker-compose restart pharma-frontend
          Clear browser cache

Problem: Services not in Eureka
Solution: Wait 2 minutes for registration
          Check: docker-compose logs eureka-server

Problem: Cannot connect to database
Solution: Check MySQL is running
          docker-compose logs mysql
